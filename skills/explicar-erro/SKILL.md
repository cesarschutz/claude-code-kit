# Explicar erro

Explique o erro que a pessoa colou, sem alterar nenhum arquivo.

1. Diga em uma frase o que o erro significa, sem jargão.
2. Aponte a linha do stack trace que é do código da pessoa (não de biblioteca) e abra esse arquivo para ler o trecho.
3. Dê a causa mais provável e diga o que confirmaria ou descartaria essa causa.
4. Sugira a correção em poucas linhas. Só edite arquivos se a pessoa pedir.

Se o erro não trouxer informação suficiente, diga o que falta (versão, comando rodado, entrada usada) em vez de adivinhar.
